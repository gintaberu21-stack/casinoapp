# CASINO DUEL

専門学校の文化祭向けに制作中の、必殺技カード付きブラックジャックです。

## 現在の状態

スマホ2台のオンライン対戦まで実装済みです。Express + WebSocketのホスト権威方式で、ID検索、申し込み、承認、対戦開始、コイントス、ターン、手札、必殺技、現物チップ、借金、ラウンド結果を同期します。各プレイヤーは手持ちの赤・青・黒チップから複数枚を選んで賭けます。MongoDBがあれば在席と試合結果を保存し、ローカルではメモリ保存で動きます。文化祭向けの本番環境は、サインイン・合言葉なしでURLからすぐ遊べます。

初回だけニックネームを登録し、ブラウザに保存した端末キーで同じアカウントへ自動接続します。MongoDBには固定PLAYER ID、ニックネーム、所持チップ、借金、前回ベット、勝敗数を保存します。ホームのアカウント設定から名前変更、戦績から対戦数・勝ち・負け・引分を確認できます。パスワードがないため、別ブラウザや別端末へのアカウント移行機能はありません。

「ふたりで対決」を選ぶと、1台を交代で使う「この端末でプレイ」と、別端末をID接続する「ローカル対戦」を必ず選択します。

ゲームは赤100チップ5枚・青500チップ3枚・黒1000チップ1枚（合計3000）からの全3ゲーム制です。毎ゲーム、手持ちから選んだチップをテーブルへ移し、勝てば賭けたチップと同じ構成が2組、引き分けなら1組戻り、負けると戻りません。チップが0以下になった場合だけ退出でき、続行すると青500チップ1枚・借金500が追加され、以後の勝利利益は返済に優先されます。最終勝敗はチップから借金を引いた純資産で判定します。通常は3ゲーム終了まで途中退出できず、終了後に再戦かロビー退出を選びます。オンライン再戦は両者が希望した場合だけ開始します。8種類の必殺技カードを重複なしに3枚ずつ配り、使用済みカードは試合終了まで復活しません。

## 構成

- `dist/index.html` — ロビー、ゲームテーブル、説明画面
- `dist/styles.css` — レスポンシブUIとアニメーション
- `dist/js/deck.js` — 山札と得点計算
- `dist/js/skills.js` — 必殺技カードの定義
- `dist/js/game.js` — ゲーム状態と勝敗判定
- `dist/js/ui.js` — カード表示と演出
- `dist/js/app.js` — 画面操作とゲーム進行
- `dist/js/sound.js` — Web Audioで合成する効果音
- `dist/js/match.js` — WebSocket接続、ID採番、対戦申し込み、状態中継
- `dist/js/matchUI.js` — 相手検索ページと対戦部屋
- `server/index.js` — 静的配信、WebSocketハブ、試合結果API
- `server/access.js` — 共有者向け合言葉ゲート
- `server/db.js` / `server/store.js` — MongoDBとローカル用メモリ保存
